# MS Project – LaPerfuma E-Commerce Web-Based System

## Project Overview

This project was developed using Microsoft Project to plan and manage the development of a web-based e-commerce system.

## Project Planning

The project plan includes different phases of the system development lifecycle, including:

- Project Initiation
- Requirement Analysis
- System Design
- System Development
- Task Scheduling
- Resource Planning
- Milestone Management
- Task Dependencies

## Tools Used

- Microsoft Project
- Gantt Chart
- Project Scheduling
- Resource Management
- Task Dependency Management

## Key Features

- Structured project phases and tasks
- Task duration and scheduling
- Task dependencies
- Resource allocation
- Project milestones
- Gantt chart visualization
- Project timeline management
